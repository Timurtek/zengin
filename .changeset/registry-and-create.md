`zengin create <dir> --template blank|marketing|review` scaffolds a project that owns its components shadcn-style: files copied in with the owned pragma, definitions in `zengin/`, the engine, MCP server, hook and Storybook wired from the first commit. `zengin add <items>` pulls more components or templates from the registry. `zengin tokens` compiles the token JSON to CSS. `zengin registry build` produces the registry the marketing site serves.
